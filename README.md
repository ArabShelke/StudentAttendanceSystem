# Student Attendance Management System

A web-based Student Attendance Management System developed using Python Flask, HTML, CSS, and JavaScript. The application provides a digital platform to manage student records, track attendance, and maintain attendance history.

## Overview

The system simplifies attendance management by providing an organized interface for maintaining student information and recording attendance. It aims to reduce manual work and make attendance records easier to manage.

## Key Features

- Student record management
- Attendance tracking and management
- Attendance history maintenance
- Web-based user interface
- Organized student information
- Backend integration using Python Flask

## Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/ArabShelke/StudentAttendanceSystem.git
```

**2. Navigate to the project directory**

```bash
cd StudentAttendanceSystem
```

**3. Create a virtual environment**

```bash
python -m venv .venv
```

**4. Activate the virtual environment**

Windows:

```bash
.venv\Scripts\activate
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Run the application**

```bash
python run.py
```

Open the local URL displayed in your terminal to access the application.
